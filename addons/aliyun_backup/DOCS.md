# Home Assistant Add-on:

# 阿里云盘自动备份插件 / Aliyun Drive Daily Backup

![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/aliyun.png)

## 使用方法

1. 在插件库的右上角选择添加: https://github.com/happyks/Home-Assistant-Addons
   ![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/add.png)
2. 选择 Aliyun Drive Backup 点击安装
   ![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/install.png)
3. 设置备份计划和备份目录名称后启动插件
   ![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/1.png)
   ![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/2.png)
4. 左侧菜单选择 CN-Backups 使用阿里云盘手机 app 完成扫码登录。
   ![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/scan.png)
5. 完成并等待定时备份到阿里云盘
   ![Aliyun Image](https://ghproxy.net/https://raw.githubusercontent.com/happyks/Home-Assistant-Addons/main/addons/images/aliyun.png)
